# 原生同窗 Tab 实施与验证

2026-10-16，依据用户确认的 `docs/design/ermi-tabs/index.html`（含下拉框修订）。

## 实施结果

- 详情窗口统一初始尺寸 980×812 pt，固定顶部「系统概览 / 风扇预设 / 图标整理」与底部状态栏；内容区独立滚动，支持 ⌘1/2/3 切换。切页不重建 NSWindow，表单状态保存在详情视图外层，排序沿用原 model。
- 概览首排改为 CPU、内存、CPU 温度和实际风扇读数；趋势采用已有 CPU 与内存历史。GPU 利用率、磁盘、网络、电池仅保留待接入说明。
- 预设与图标页按设计重排，700 pt 以下采用上下布局；下拉框 34 pt 高、8 pt 圆角、箭头侧 13 pt 留白。宽窗导航保持紧凑且标签单行。
- 正式模式不展示示例配置为实际设置：预设参数显示「—」并禁用，图标分组为空，控制与图标管理维持待接入。AppleSMC、采样和进程信号实现未改。
- 真实风扇名称沿用采样结果，缺失描述按编号显示，不从设备编号推断物理左右。

## 验证

- 最终 Release 构建及本机 ad-hoc 签名通过；`swift test` 16 项通过（含真实读取及测试自身子进程操作）。未增加复述布局实现的机械测试。
- 使用共用 SwiftUI 视图导出三页固定样本图、600 pt 窄窗预设图、实际数据概览与原主浮层，位于 `output/native/tabs/`。固定样本均需显式 `--design-reference`；`*-live.png` 为短时真实读数，非完整一分钟历史。
- Computer Use 原生窗口验证：点击三页 Tab，⌘1/2/3 切换；按内存排序后切页再返回仍选中内存；进程确认框能打开并用 Escape 取消，原进程仍在列表；风扇页输入/保存/恢复、图标页开关在正式模式均禁用；主浮层「图标整理」入口直达详情对应 Tab。
- UI 复核发现宽窗口标签换行，已修为单行并重新构建、导出目视核对。卡片与下拉箭头留白通过。原生字体、符号与系统开关外观存在平台差异，不声明逐像素一致。
- 设计模式表单保留依据外层状态结构检查；未对原生诊断样本进行实际手工输入切页验收。系统睡眠、多显示器、全部动效不在本轮完整验收范围。
