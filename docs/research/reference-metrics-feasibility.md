# 参考图指标可行性评估

日期：2026-10-15。用户请求为评估截图中哪些数据可添加，以下为候选建议，不修改已确认的首版功能范围，也不代表已实现硬件采集。

## 建议分级

| 参考图项目 | 评估 | 建议与边界 |
| --- | --- | --- |
| 芯片、内存总量、macOS、运行时间 | 可添加，基础展示 | 运行时间按系统启动时间计算，与 App 打开时长区分 |
| CPU 使用率、逐核占用与历史 | 优先候选 | 核心占用与历史趋势不能混为同一图表；采样与计算口径须标注 |
| CPU 平均负载 | 可添加至详情 | 若使用 load average，应说明时间窗口，不将其当作百分比或单独评分依据 |
| CPU/GPU 温度 | 与现有风扇模块结合 | 传感器名称、位置与聚合规则需核实，不能凭 SMC key 名称假设其对应具体核心 |
| GPU 使用率与趋势 | 支持设备验证后添加 | 在本机验证来源、空闲态和负载态后再承诺兼容机型 |
| GPU 2.3 W 等功耗 | 后续研究 | 来源可能是特定传感器或采样工具；不能将 GPU、芯片封装或整机功率互相替代 |
| 内存占用、已用/总量、压力 | 优先候选 | 与活动监视器核对计算口径；内存使用率高不等于内存压力高 |
| 磁盘可用、已用、总量与百分比 | 可添加，次级概览 | 同一卷及同一容量口径；APFS 可清除空间会影响不同工具的结果；GB/GiB 必须一致 |
| 网络上传下载速度与趋势 | 可添加，次级概览 | 取接口字节计数差值计算速率；处理 VPN、虚拟网卡、接口切换及重复统计；明确上/下行 |
| Wi-Fi 标记 | 可添加连接类型 | 与读取网络名/SSID 区分；后者的权限和版本行为需另核实 |
| 风扇 RPM、模式及预设 | 已在原首版范围 | 两侧风扇分别展示；100% 需已知各自转速上限，不能将目标值当作实际值 |
| 电量和充电状态 | 可添加 | 通过电源信息区分充满、充电、接通电源未充电等状态 |
| 电池健康度和循环数 | 验证后添加 | 容量单位、设计容量与最大容量语义须核实；与系统电池页面对照，不凭字段名拼接公式 |
| 高占用 App/进程 | 优先研究 CPU Top 列表 | 采样开销、系统进程可见性及 App 多进程聚合需要验证；区分按进程 CPU 与整机 CPU 的分母，不应直接相加对比 |
| 摄像头/麦克风使用状态 | 后续扩展 | 系统和设备 API 有相关能力；多设备、占用者归因、权限变化须实测。无权限或来源不可靠时显示未知，不能显示未使用 |
| 常亮开关 | 可做独立小工具 | 是防休眠操作，与只读监控分开；状态、作用范围及结束条件必须明确 |
| 清洁按钮 | 意义不明，暂不定范围 | 图标可能表示屏幕清洁模式，不能自动解释为垃圾清理；需先确认原产品含义 |
| 90 分/很好 | 暂不建议 | 没有评分算法、权重或阈值来源；建议以系统热状态、内存压力等有明确语义的独立状态表达 |
| 已清理、已卸载、已优化 | 暂不建议 | 需要本 App 真实执行对应工作并记录结果；不是可直接读取的系统统一累计量 |
| 开启低延迟 | 暂不建议 | 截图没有给出具体作用；不能从网速监控推导出通用网络加速能力 |

## 与当前目标的关系

最有价值的增量是解释负载：CPU、内存及高 CPU 占用进程，再将真实温度与风扇状态放在同一视图。高 CPU 占用能提示持续计算负载，不能仅凭高内存占用把 App 认定为发热原因。

布局建议：风扇控制仍是核心操作；CPU/内存为摘要，GPU/磁盘/网络/电池为可折叠详情，高占用列表按需展开。避免把参考图的整张长面板直接复制到菜单栏浮层中。

所有“可添加”均指有可研究的系统信息路径，尚未编写采集器或进行目标 App 权限与签名环境验证。不得据此承诺读取完全免授权、支持所有 Mac 或可直接通过特定分发渠道。

## 证据

- [Apple host_statistics64](https://developer.apple.com/documentation/kernel/1502863-host_statistics64)：系统 Mach 统计接口。
- [Apple getifaddrs](https://developer.apple.com/library/archive/documentation/System/Conceptual/ManPages_iPhoneOS/man3/getifaddrs.3.html)：接口和 AF_LINK 统计数据。
- [Apple IOPowerSources.h](https://developer.apple.com/documentation/iokit/iopowersources_h)：电源信息接口。
- [Apple 内存使用说明](https://support.apple.com/en-sg/guide/activity-monitor/actmntr1004/mac)：内存压力结合可用内存、交换、压缩等因素，不能替代为占用百分比。
- [Apple thermalState](https://developer.apple.com/documentation/foundation/processinfo/thermalstate-swift.property)：系统热状态，与自定义综合分数区分。
- [Apple AVCaptureDevice.inUseByAnotherApplication](https://developer.apple.com/documentation/avfoundation/avcapturedevice/isinusebyanotherapplication)：特定设备使用状态，不等价于已验证的全系统隐私审计能力。
- [Stats 官方仓库](https://github.com/exelban/stats)：公开提供 CPU/GPU、内存、磁盘、网络、电池与传感器监控，说明不同芯片传感器映射需要适配；功能存在不代表本项目已有相同实现。

本次本机只读探针确认了硬件型号、64 GiB 内存、启动时间和数据卷空间可读取。没有读取完整敏感进程列表，也未执行风扇、网络、电源或清理操作。
