# Ermi v0.1.1 — Universal Preview / 通用预览版

This release expands temperature and fan compatibility beyond the original M1 Max implementation and provides a Universal installer for Intel and Apple Silicon Macs running macOS 14+.

本版本将温度与风扇控制从 M1 Max 专用实现扩展为跨机型能力适配，提供适用于 macOS 14+、Intel 与 Apple Silicon 的 Universal 安装包。

## Changes / 更新

- Chip-family temperature mappings for Intel and supported Apple Silicon families, including M4 / 按芯片族适配温度映射，包含 M4。
- Dynamic single-fan, multi-fan and fanless handling / 按硬件实际风扇数量展示与编辑，无风扇设备保留监测。
- Intel FS! and Apple Silicon per-fan control protocols with readback and recovery protections / 扩展控制协议，保留回读确认、租约与恢复保护。
- Unsupported hardware reports capability errors instead of exiting the helper before connection / 不支持的硬件明确显示能力限制，避免 helper 启动退出导致连接超时。

## Upgrade / 升级

Quit Ermi, drag the new app into Applications, then choose **Install / Update Authorization** on the fan page to update the helper. The old installed helper is not replaced simply by copying the app. Installation does not apply a fan preset.

退出 Ermi，将新版拖入“应用程序”，然后在风扇页面点击 **安装 / 更新授权** 更新 helper。仅替换 App 不会更新已安装的旧 helper；安装本身不会应用风扇预设。

The preview is locally signed and **not Apple-notarized**. If macOS blocks it, use Privacy & Security → Open Anyway only if you trust the download and the system offers that option.

此预览版使用本机签名，**未经 Apple 公证**。若 macOS 拦截，确认来源可信后，可使用系统提供的“隐私与安全性 → 仍要打开”。

```sh
shasum -a 256 -c Ermi-0.1.1-universal-preview.dmg.sha256
```

## Validation and limits / 验证与限制

- 141 Swift Testing tests and 1 XCTest passed / 142 项测试通过。
- Universal App and helper build, strict signatures, read-only smoke probe and DMG verification passed / 双架构构建、严格签名、只读冒烟与安装包校验通过。
- Hardware checks remain on M1 Max. M4 and Intel control paths have simulated tests, not comprehensive hardware write validation / 真机检查仍限 M1 Max；M4、Intel 控制路径有模拟测试，尚未完成全面真机写入验收。
- Unknown sensors or protocols remain unavailable; Intel devices without the verified FS! protocol are not enabled for writes / 未知传感器与协议明确不可用，缺少已核实 FS! 协议的 Intel 设备不开放写入。
- macOS 14+ only; no automatic updater / 仅支持 macOS 14+，暂无自动更新。
