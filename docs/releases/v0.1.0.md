# Ermi v0.1.0 — Preview / 预览版

The first public preview of Ermi: a native macOS menu bar app for monitoring, cooling, and icon organization.

Ermi 首个公开预览版：在菜单栏中查看系统状态、调节风扇并整理图标。

## Highlights / 主要功能

- CPU, memory, disk, battery, network, and process monitoring / 系统与进程监控。
- Temperature readings, fan RPM, fixed speeds, and custom cooling presets / 温度、转速与散热方案。
- Menu bar icon grouping and temporary expansion / 菜单栏图标分组与临时展开。
- Six color themes, custom colors, and English / 简体中文 / 繁體中文。

## Installation / 安装

Open the DMG and drag Ermi into Applications. Launch it and click the menu bar icon. Fan control requires installation authorization through the app and a macOS administrator prompt. Menu bar permissions are separate.

打开 DMG，将 Ermi 拖入“应用程序”，启动后点击菜单栏图标。风扇服务需在 App 内安装授权并完成管理员验证；图标整理权限需单独开启。

This preview is locally signed, **not Apple-notarized**. If macOS blocks it, use Privacy & Security → Open Anyway only if you trust the download and the system offers that option.

预览版为本机签名，**未经 Apple 公证**。若被系统拦截，确认来源可信后，可使用系统提供的“隐私与安全性 → 仍要打开”。

```sh
shasum -a 256 -c Ermi-0.1.0-arm64-preview.dmg.sha256
```

## Known limitations / 已知限制

- Other Mac models and older macOS versions need further hardware validation / 其他机型及旧系统仍需实机验证。
- Menu bar organization uses version-dependent behavior, including experimental private APIs on macOS 27 / 图标整理依赖系统版本，macOS 27 路径使用实验性私有接口。
- Full third-party menu interaction and real sleep/wake fan recovery are not fully validated / 第三方菜单交互及真实睡眠唤醒风扇恢复尚未完整验收。
- No automatic updater / 暂无自动更新。

Report issues: https://github.com/lay215/Ermi/issues
