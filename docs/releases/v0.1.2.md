# Ermi v0.1.2 — Helper Installation Fix / 风扇服务安装修复

Fixes the Universal helper installer failing with `test-requirement: code failed to satisfy specified code requirement(s)`. This failure left the old helper installed, preventing affected M4 machines from connecting to the fan service.

修复 Universal 风扇服务安装时的签名校验错误：此前更新会在替换旧 helper 前失败，导致 M4 继续运行不支持该机型的旧服务并连接超时。

## Changes / 更新

- Validate signatures for all architectures, then validate the authorization CDHash against the selected execution architecture. Preserve rejection of wrong hashes and tampered binaries.
- Pin the same architecture for the installation plan and privileged execution, including the uninstall path.
- 保留全架构签名完整性验证，按实际执行架构核对授权哈希；不删除或绕过签名校验。
- 安装计划与提权后的执行固定使用同一架构，卸载入口同步修正。

## Upgrade / 升级

1. Quit Ermi and replace the app in Applications.
2. Open Ermi, choose **Install / Update Authorization** in Permissions & Services, and complete administrator authorization. Copying the app alone does not update the installed helper.
3. Reconnect to the fan service. Installation does not apply a preset.

退出 Ermi，替换“应用程序”中的 App，再到 **系统设置 → 权限与服务 → 安装 / 更新授权** 完成管理员验证。仅替换 App 不会更新旧 helper。安装不会应用调速预设。

```sh
shasum -a 256 -c Ermi-0.1.2-universal-preview.dmg.sha256
```

## Validation / 验证

- Both architecture hashes and explicit-architecture installation plans validated; incorrect hashes, hashes from the other slice, and a tampered other slice rejected. The same regression check reproduces the original installer failure.
- Universal build, strict signatures and DMG checksum verified.
- User-provided M4 Pro diagnostics confirm successful installation, `connected=true phase=applied capabilities=1 error=none`, and manual-mode readback with target 1000 RPM and actual approximately 1000 RPM. This does not establish full-range speed or failure-recovery validation.
- 双架构安装校验回归通过；M4 Pro 用户实测安装及连接恢复，控制方案已应用，模式与目标转速回读一致。未宣称全部转速范围和故障恢复均完成真机验收。

## Known limitations / 已知限制

**M4 Pro temperature issue is NOT fixed in this release.** Some CPU sensor keys return suspicious low or constant values, causing the displayed average to alternate around 15°C and 43°C. Independent Stats and Ermi readers returned matching values. This also affects automatic temperature-based control. Use system fan control until the temperature issue is resolved.

**本版本未修复 M4 Pro 温度问题。** 部分 CPU 传感器键返回可疑低值或固定值，平均温度可能在约 15°C 与 43°C 间跳动，并影响自动温控。Stats 与 Ermi 独立读取结果一致。温度问题解决前建议使用系统风扇控制。本次不变更温度映射或过滤规则。

macOS 14+, Intel and Apple Silicon. Preview signed with a local identity, not notarized by Apple. No automatic updater. / 支持范围不变：macOS 14+、Intel 与 Apple Silicon。本机签名预览版，未经 Apple 公证，无自动更新。
