# Ermi v0.1.3 — Sensor Selection & Menu Bar / 温控来源与菜单栏改进

## Changes / 更新

- Choose CPU, GPU, their maximum, or an individual SMC sensor directly for built-in cooling presets. The popover follows the selected source and shows CPU/GPU temperatures alongside it.
- 内置散热方案支持直接选择 CPU、GPU、两者最高值或具体 SMC 温度键；弹窗主温度同步来源，右侧统一展示 CPU/GPU 温度。
- Missing or invalid sensor readings reject control or trigger recovery without switching sources. Individual sensor control requires a helper that explicitly supports it.
- 温度缺失或无效时拒绝控制或触发恢复，不静默换源；旧 helper 会提示更新，保存方案不会自动应用。
- Keep Visible, Folded, and Hidden icon groups; compact tray opening, entry filtering, icon capture, lifecycle handling, and shared app ordering improved.
- 菜单栏保留、收起、隐藏三组及紧凑展开栏完善；改进入口过滤、图标采集、启停处理和共享排序。macOS 27 支持同步系统菜单栏顺序。
- Refresh README screenshots from this build and synchronize English/Chinese download links.
- 更新本版真实界面截图，统一中英文下载入口。

## Upgrade / 升级

Quit Ermi, replace the app in Applications, then update the helper through **Settings → Permissions & Services → Install / Update Authorization**. Installing the helper does not apply a preset. Older apps may not read presets containing the new individual-sensor source.

退出 Ermi，替换“应用程序”中的 App，再到 **系统设置 → 权限与服务 → 安装 / 更新授权** 更新 helper。安装不会应用方案。含具体传感器来源的预设可能无法被旧版程序读取，请谨慎降级。

```sh
shasum -a 256 -c Ermi-0.1.3-universal-preview.dmg.sha256
```

## Known limitations / 已知限制

M4 Pro CPU temperature mapping is not corrected by this release. Explicit sensor selection is not proof of the physical meaning or accuracy of an arbitrary SMC key. Use system fan control when readings are unreliable.

本版未修复 M4 Pro CPU 默认温度映射问题。支持具体键选择不代表已经验证每个键的物理含义或准确性；读数不可靠时请使用系统风扇控制。

Menu bar organization depends on permissions and macOS behavior; macOS 27 uses experimental private APIs. Universal compilation and automated tests do not establish full hardware, third-party menu, or sleep/wake acceptance. No automatic updater.

图标整理依赖权限和系统行为，macOS 27 使用实验性私有接口。通用构建及自动化测试不代表所有机型、第三方菜单和睡眠唤醒场景完成验收。暂无自动更新。
