# 原生 macOS 架构与独立分发

2026-10-16 确认 SwiftUI 内容与 AppKit 菜单栏/窗口外壳；2026-10-19 更新为开源维护，支持从源码构建本机 App。结束其他 App 与硬件控制的需求不适合以 App Store 沙盒为前提；普通监控留在非特权 App，风扇写入通过最小特权服务隔离，具体设备协议先验证再启用。

首个验证版本针对本机 M1 Max。先交付真实监控与进程操作，再接入经验证的风扇和图标整理；跨机型支持尚未完成验证。开发基线暂用 macOS 14，便于使用 Observation，实际兼容性以实机验证为准。

本机开发例外：2026-10-16 增加显式管理员安装的 ad-hoc 构建模式，以 root 保存的精确 App/helper cdhash 和安装用户身份替代 TeamID 信任。该模式用于本机验证，保留调用方身份检查与管理员授权。重新构建必须重新授权；硬件支持范围、接管租约与自动恢复规则保持一致。
